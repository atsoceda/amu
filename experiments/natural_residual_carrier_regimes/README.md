# Natural residual carrier regimes

Compares the same natural pre-article residual-state transplant in two held-out
regimes: source/target nouns with different article classes (the public article
is informative) and with the same article class (the public article is
uninformative). Prompts never name the target noun. The experiment uses a
pooled development set for layer selection and includes cyclic wrong-target,
sign-reversed, and reverse natural-patch controls.
