# S1 × generated-article factorial

This is the acceptance-critical decomposition of the exact S1 intervention
that changes article–noun completions under free generation.

The complete pre-specified E1 held-out set is evaluated under:

- S1 off/on;
- free article, forced `a`, and forced `an`;
- recomputed attention (primary) and frozen attention (mechanistic ablation).

For forced-article cells, S1 remains active at the original pre-article
position during noun prediction. The primary comparison therefore holds the
visible prefix exactly constant and varies only the internal S1 intervention.

Run from the repository root:

```bash
/Users/anthony/miniconda3/bin/python experiments/s1_article_factorial/run.py
```

Outputs:

- `results/rows.json`: per-prompt cells and distributional comparisons;
- `results/summary.json`: prompt-level bootstrap summaries;
- `results/tokenization.json`: source/twin tokenization audit;
- `results/report.md`: concise result report.
- `manuscript/figures/fig_mediation_decomposition.png`: generated by
  `plot.py` after both the factorial and full-residual reference have run.

The S1-switching subset is descriptive only. Inferential summaries use all
pre-specified held-out prompts; twin-target effects use only the seven
pre-specified twin pairs.
