# S2 feature decomposition

Runs the frozen S2 features individually and in leave-one-out combinations on
the same 20 held-out prompts. Each condition includes free generation and a
fixed-`an` noun distribution. The analysis separates grammatical-continuation
validity from pre-specified twin target movement.
