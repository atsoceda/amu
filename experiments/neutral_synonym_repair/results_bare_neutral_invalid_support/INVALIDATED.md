# Invalidated bare-neutral pilot

This preliminary run used the bare template `{definition} is`. Although its
conditional `a/an` route interaction had the predicted sign, it is excluded
from all scientific inference because the evaluated prompts did not reliably
remain in the intended mediator domain: mean intervention-off `a/an` mass was
about 0.27 and only 7/14 greedy continuations began with `a` or `an`.

The retained primary run adds one unrelated occupation-format demonstration.
It contains no tested synonym, initial, or article-class cue, but restores mean
intervention-off `a/an` support to 0.909 (minimum 0.854). The archived files are
preserved solely as an audit trail.
