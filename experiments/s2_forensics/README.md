# S2 forensic analysis

This analysis reuses the frozen six-cell family-sweep rows. It determines
whether S2's relatively large fixed-`an` distributional effect behaves like a
target-specific noun plan or like continuation disruption.

It reports legal free-generation rates, forced-prefix top-1 stability,
pre-specified twin direction consistency, concentration of the effect across
prompts, and a lower bound on probability mass assigned to the pre-specified
held-out occupation/twin vocabulary within the stored top-10 tokens.

No model forwards are performed.
