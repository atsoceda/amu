# Working-paper layout

The active paper has no selected venue. This internal header loads the unmodified
ICLR 2027 style for its layout and bibliography, then replaces the style's visible
claims that the paper is under ICLR review. It is **not** an official venue style
and must not be used as a submission template without venue-specific review.

The official files remain in `../iclr/`; their source and checksums are unchanged.
